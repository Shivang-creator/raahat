# craft/

Distilled from several thousand winning hackathon submissions scraped in August 2026. These are
patterns that repeatedly separated winners from the rest, not rules invented for this project.

Read them for judgement, not instructions. `SPEC.md` and `AGENTS.md` always win where they disagree.

| File | Read it before |
|---|---|
| `design.md` | building any screen — especially the signature-moment section |
| `engineering.md` | writing the rule file and the routing function |
| `deploy.md` | the Slice 0 deploy, and every deploy after it |
| `verification.md` | checking your own work at the end of a slice |

The single most useful idea across all four: **decide the one moment a judge will screenshot, build
that first, and build the rest around it.** For Raahat that moment is the body map producing a
department with a cited reason, on a phone, without typing.
